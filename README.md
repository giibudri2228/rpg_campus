## Sobre o projeto

RPG Campus é um jogo mobile desenvolvido em Flutter no contexto da disciplina de Programação para Dispositivos Móveis (PI3).

## Estrutura de pastas

```
lib/
  main.dart          # Ponto de entrada do app
  models/            # Classes de dados (entidades do jogo)
  data/              # Dados estáticos, listas, seeds
  services/          # Lógica de negócio e acesso a dados
  screens/           # Telas do app
    home_screen.dart # Tela inicial
  widgets/           # Componentes reutilizáveis
```

## Como rodar

1. Certifique-se de ter o Flutter 3.41.5+ instalado
2. Clone este repositório
3. Execute:

```bash
flutter pub get
flutter run
```
